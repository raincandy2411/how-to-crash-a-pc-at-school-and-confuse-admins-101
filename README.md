That's it, that's all you need to crash a PC and put it into temporary recovery mode on boot :)
The reason this works is because it creates a ___fork bomb___, a type of self-replicating program.
by typing `%0|%0` you're telling the program to run itself again, at the same time as the first program. So then the second program creates a copy of itself, as does the first program again.
Over and over to infinity!
But computers don't have infinite memory. Eventually copies of this program will take over everything and leave no room for other processes, causing a crash.
Thankfully, it causes no lasting damage! It only affects the RAM usage (the computer's short term memory.)
So you can cause a crash without actually damaging anything.
